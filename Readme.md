# Сайт для учета пробников ЕГЭ/ОГЭ и аналитики успеваемости

Веб-приложение для учителей и образовательных центров, предназначенное для организации учета диагностических срезов и пробных экзаменов, быстрого ввода баллов с автоматическим пересчетом первичных результатов во вторичные (по шкалам ФИПИ), анализа успеваемости классов и мониторинга индивидуальной траектории учеников.

---

## 🚀 Основные возможности

1. **Авторизация и профили:**
   - Вход в личный кабинет учителя с поддержкой JWT-токенов.
   - Быстрый демонстрационный вход в один клик.

2. **Главная страница (Дашборд):**
   - Сводные показатели по всем группам: количество классов, учеников, проведенных срезов и средний балл по школе.
   - Журнал последних пробников с индикаторами статуса готовности ведомостей.

3. **Управление классами (`/classes`):**
   - Создание классов с указанием параллели (5–11), литеры (буквы) и предмета подготовки.
   - Управление списком учащихся: одиночный ввод или пакетный импорт (копирование списка ФИО из электронного журнала или Excel).
   - Редактирование параметров и удаление классов.

4. **Управление пробниками (`/mock-tests`):**
   - Создание пробных работ с привязкой к классу, предмету, дате и учебному году.
   - Автоматическая подгрузка спецификаций заданий по стандартам ФИПИ (профильная математика, русский язык, информатика, физика, обществознание и др.).
   - Гибкая настройка структуры заданий (изменение максимального балла за конкретный номер, добавление/удаление заданий).

5. **Интерактивная ведомость ввода результатов (`/mock-tests/:id/results`):**
   - Матричная таблица ввода оценок (ученики $\times$ номера заданий) с фиксацией столбцов с ФИО.
   - **Валидация на лету:** визуальное предупреждение и блокировка при превышении максимального балла задания.
   - **Автоматический расчет:** мгновенное суммирование первичных баллов.
   - **Автоперевод во вторичные баллы:** автоматический перевод первичного балла во вторичный (шкала 0..100) по официальным таблицам соответствия ФИПИ.
   - Кнопка автозаполнения реалистичными демо-данными для быстрого тестирования.

6. **Аналитический модуль (`/analytics`):**
   - Выбор класса и среза.
   - Ключевые метрики (KPI): средний первичный и вторичный балл, разброс результатов (минимум/максимум), доля высокобалльников (80+).
   - Интерактивный регулятор порога сдачи с мгновенным пересчетом доли сдавших учеников.
   - Диаграмма распределения результатов по интервалам баллов (`0–39`, `40–59`, `60–79`, `80–100`).
   - График динамики среднего балла между всеми пробниками класса с отображением прироста ($+X$ б.).
   - Анализ решаемости заданий (% выполнения каждого номера) для выявления проблемных тем.

7. **История пробников (`/history`):**
   - **По классам:** хронологический реестр всех диагностик с переходом к ведомости и аналитике.
   - **По ученикам:** персональная карточка ученика, средний и максимальный балл, динамика относительно класса, полная история попыток и раскрывающаяся детализация баллов по каждому заданию.

## 🛠 Технологический стек

### Frontend
- **Фреймворк:** [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Сборщик:** [Vite](https://vitejs.dev/)
- **Стейт-менеджмент:** [Pinia](https://pinia.vuejs.org/)
- **Маршрутизация:** [Vue Router](https://router.vuejs.org/)
- **Иконки:** [@lucide/vue](https://lucide.dev/)
- **HTTP-клиент:** Axios

### Backend
- **Фреймворк:** [Django 6.1](https://www.djangoproject.com/) + [Django REST Framework](https://www.django-rest-framework.org/)
- **Аутентификация:** `djangorestframework-simplejwt`
- **База данных:** PostgreSQL (`psycopg2-binary`)
- **Пакетный менеджер:** `uv`
- **Линтер и форматтер:** Ruff

## ⚡ Инструкция по запуску

### 1. Запуск Frontend

Перейдите в каталог `frontend`:
```bash
cd ~/Projs/frontend
```

Установите зависимости (если еще не установлены):
```bash
npm install
```

Запустите сервер разработки:
```bash
npm run dev
```

После запуска перейдите в браузере по адресу:  
👉 **[http://localhost:5173/](http://localhost:5173/)**

#### Быстрый вход (Demo-аккаунт):
- **Логин:** `teacher`
- **Пароль:** `teacher123`  
*(На странице входа доступна кнопка быстрого заполнения «Учитель (teacher)»)*

---

### 2. Сборка Frontend для продакшена

Для проверки типов TypeScript и сборки оптимизированного бандла:
```bash
cd ~/Projs/frontend
npm run build
```

---

### 3. Запуск Backend (Django)

1. Создайте файл конфигурации `.env` в корне проекта на основе шаблона:
   ```bash
   cp .env.example .env
   ```
2. Укажите параметры подключения к базе данных PostgreSQL и секретный ключ `SECRET_KEY`.
3. Примените миграции и запустите бэкенд:
   ```bash
   cd ~/Projs/backend
   python3 manage.py migrate
   python3 manage.py runserver
   ```
   Сервер API будет доступен по адресу `http://localhost:8000/`.
